
The placeholder is a base64 SVG data URI — small enough to inline, and it renders instantly as a
blurred backdrop while the real image loads.

## How the widths are chosen

The default `FileSizeOptimizedWidthCalculator` is a port of Spatie's. It targets roughly **70% of the
previous predicted file size** for each successive variant. Because file size scales with pixel area
at a constant bytes-per-pixel, width shrinks by `√0.7` per step — about 84% each time.

It stops when the predicted size drops below 10 KB or the width below 20 px. A 1600 px source
typically yields five or six variants; a small image may yield one.

Swap the strategy if that doesn't suit you:

```ts
createMediaLibrary({
  responsiveWidthCalculator: new FileSizeOptimizedWidthCalculator(), // the default
  responsivePlaceholders: true, // set false to skip LQIP generation
})
```

A custom calculator implements one method:

```ts
interface WidthCalculator {
  calculateWidths(fileSizeBytes: number, width: number, height: number): number[]
}
```

## Where the variants live

On the media's own disk, beside the original:

```
{mediaId}/responsive/{base}___{conversion}_{width}_{height}.{ext}
```

So `photo___original_1600_1200.png` for the source's own variants, and `photo___hero_1600_1200.webp`
for a conversion's. The `original` pseudo-conversion name is why `original` and `requested` are
reserved and can't be used as conversion names — the builder throws if you try.

<Aside type="caution" title="Turning this on doesn't backfill">
  Adding `.withResponsiveImages()` to a collection that already holds media generates nothing
  retroactively. Run `regenerate({ withResponsive: true, onlyMissing: true })`, or the equivalent
  `node-media-library regenerate --with-responsive --only-missing`. See [the CLI
  reference](/reference/cli/).
</Aside>

## Cost

Responsive generation is real work: each variant is a full sharp re-encode of the source. For a
gallery accepting large uploads, leave conversions queued (the default) so it happens on a worker
rather than in the request — see [background conversions](/guides/background-conversions/).
